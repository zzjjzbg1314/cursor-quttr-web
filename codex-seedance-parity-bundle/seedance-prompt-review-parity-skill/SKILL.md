# Seedance 提示词审核对齐版

## 审核流程

1. 读取导演讲戏本、人物资产库、场景资产库和提示词产物
2. 逐条比对导演意图与提示词
3. 做 Seedance 生成效果的脑内预演
4. 检查素材映射表是否准确
5. 输出 `PASS` 或 `FAIL`

## 核心检查项

- 核心动作、台词、运镜、光影是否忠实保留
- 是否存在动作顺序冲突或镜头物理矛盾
- 是否使用叙事描述式而不是标签堆叠
- 是否包含基本音频设计
- 群演和一次性角色是否正确用文字描述
- 每条提示词的引用数量是否在平台限制内
- 场景引用是否按单格拆分，而不是整张宫格
- 相邻提示词之间的时间、空间、情绪是否连续

## 输出格式

- `PASS`：给简要评分结论
- `FAIL`：按“位置 / 当前问题 / 脑内预演 / 修改方向”列问题
- 如需评分，可按忠实度、画面还原、动作可执行、镜头可实现、Seedance 友好、音频设计、情绪准确七维打分
