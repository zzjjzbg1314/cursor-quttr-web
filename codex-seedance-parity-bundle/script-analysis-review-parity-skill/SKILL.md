# 导演分析审核对齐版

## 审核目标

用批判性视角找问题，不要默认通过。

## 审核流程

1. 读取原始剧本和 `outputs/<集数>/01-director-analysis.md`
2. 逐个剧情点比对是否遗漏、弱化或偏离
3. 对每个剧情点做脑内预演，判断能否直接指导拍摄
4. 检查人物清单和场景清单是否足够支持下游设计
5. 输出 `PASS` 或 `FAIL`

## 核心检查项

- 剧情点拆分是否按叙事断点，而不是机械切片
- 每个剧情点是否只承载一个完整叙事目的
- 动作链是否连续
- 节拍密度是否合理
- 头尾安全区是否被尊重
- 镜头意图是否可执行
- 光影是否具体
- 人物清单是否漏掉 recurring 角色
- 群演外观是否在导演阐述里写清
- 场景清单是否覆盖全部关键环境

## 输出格式

- `PASS`：给 1-2 句整体评价
- `FAIL`：列出问题、位置、为什么会拍不出来、怎么改
- 如需评分，可按 10 分制给出平均分和单项低分项
