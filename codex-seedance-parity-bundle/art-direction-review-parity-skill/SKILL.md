# 服化道审核对齐版

## 审核流程

1. 读取导演讲戏本中的人物清单和场景清单
2. 读取本集新增的人物和场景提示词
3. 逐项比对原始要求
4. 对文生图效果做脑内预演
5. 给出 `PASS` 或 `FAIL`

## 人物检查项

- 与导演外观关键词是否一致
- 是否一眼可区分
- 是否存在歧义表达
- 面部、发型、体型、服装、配饰、鞋子是否完整
- 是否明确项目视觉风格
- 布局要求是否可执行

## 场景检查项

- 场景覆盖是否完整
- 宫格规格是否正确
- 每格的光线、色调、氛围是否匹配导演要求
- 整张宫格是否风格统一
- 是否能直接复制进图像模型使用

## 输出格式

- `PASS`：附 1-2 句总结
- `FAIL`：按“位置 / 当前问题 / 脑内预演 / 修改方向”给问题单
- 如需评分，可给人物分表、场景格表和总平均分
