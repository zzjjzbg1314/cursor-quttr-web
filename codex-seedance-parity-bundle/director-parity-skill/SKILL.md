# 导演执行对齐版

## 目标

把上游文本转成可以直接交给服化道和分镜的导演讲戏本，尽量保持原 Claude 版规则。

## 读取顺序

1. 源剧本
2. `templates/director-analysis-template.md`
3. 现有 `assets/character-prompts.md` 和 `assets/scene-prompts.md`（若存在）

## 执行流程

1. 通读剧本，确认核心叙事线、人物关系、情绪弧线和关键转折。
2. 按叙事自然断点拆解剧情点。每个剧情点 = 一次 Seedance 生成任务。
3. 为每个剧情点选择时长：
   - 5s：单动作或单表情变化
   - 8s：单镜头连贯动作
   - 10s：一段有镜头转换的叙事
   - 15s：多镜头蒙太奇或多场景叙事
4. 写导演阐述时，至少覆盖：
   - 画面内容
   - 人物动作链
   - 台词与环境音
   - 镜头感觉和运动方向
   - 光影与情绪
5. 提取人物清单：
   - 本集出现在 2 个及以上剧情点的人物
   - 本集只出现 1 次但后续还会复现的人物
   - 群演和一次性配角不进清单，但在导演阐述里要写清外观
6. 提取场景清单：
   - 场景名
   - 时间
   - 光线/色调
   - 氛围关键词
7. 如果已有资产库，给人物和场景标注：
   - `新增`
   - `复用 <素材ID>`
   - `变体 <素材ID>`
8. 按模板写入 `outputs/<集数>/01-director-analysis.md`。

## 讲戏原则

- 用具体动作，不用抽象评价
- 用连续动作链，让画面能拍出来
- 镜头运动必须有方向
- 光影描述要具体到光源、方向、色温或色调
- 情绪通过动作、空间、光线传达，不直接喊口号

## 质量标准

- 每个剧情点至少 3 句有效视觉描述
- 下游可以直接抽取人物、场景、运镜、动作和声音
- 人物清单和场景清单足够具体，服化道无需二次猜测
