# 导演分析模板

输出文件：`outputs/<集数>/01-director-analysis.md`

## 导演讲戏本

```markdown
## P01 [剧情标题]

- 人物：[出场人物]
- 场景：[场景]
- 镜头组：[单镜头 / 多镜头]
- 时长建议：[5s / 8s / 10s / 15s]

**导演阐述**：
[完整叙事段落]
```

## 人物清单

```markdown
| 人物 | 年龄 | 外观关键词 | 素材状态 |
|------|------|------------|----------|
```

## 场景清单

```markdown
| 场景 | 时间 | 光线/色调 | 氛围关键词 | 素材状态 |
|------|------|-----------|------------|----------|
```
