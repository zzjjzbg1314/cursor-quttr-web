# Seedance 提示词方法论

## 第一原则

- 导演意图优先
- 叙事描述式
- 参考图已见，不重复静态信息
- 一条提示词 = 一段完整叙事

## 节拍密度

- 每个连续镜头内 1 拍约等于 2.5 秒
- 多镜头段落把节拍拆到多个镜头里
- 开头 0.5 秒和结尾 0.5 秒不放关键动作

## @引用规则

- `@图片`：人物或场景参考
- `@视频`：动作、运镜或节奏参考
- `@音频`：BGM 或音效参考
- 每个引用都要明确用途

## 平台限制

- 每条提示词图片 <= 9
- 每条提示词视频 <= 3
- 每条提示词音频 <= 3
- 总文件数 <= 12
