# 场景道具提示词

## ep01 场景宫格

请生成一张 3×3 九宫格布局的电影场景环境图像。每个格子代表一个独立场景，所有格子必须保持视觉风格统一。请按照以下规范生成。

### 视觉规范
整体风格：国风武侠、真人写实、电影感构图，适配竖屏短剧的强钩子节奏
色彩基调：现代段落以冷蓝灰和手机冷光为主，穿越后段落以风雪白、夜青黑和人物肤色冷白为主
材质质感：出租屋内的廉价塑料、旧墙面、手机屏幕冷光，以及雪地、寒风、粗布披风、湿冷山路都要真实细腻

### 宫格布局
第1行：格1-3 / 第2行：格4-9留空

### Panel Breakdown（场景拆解）

格1——【现代出租屋夜】
视角：一间逼仄的现代出租屋，深夜。房间不大，墙面发旧，顶灯偏暗，床边和书桌杂乱但真实，桌上有充电线、矿泉水瓶、廉价纸巾、几本翻旧的书和一部亮着屏幕的手机。窗外是城市夜色，但被旧窗帘遮掉大半，只剩一点冷蓝光透进来。整个空间有长期独处、克制欲望、咬牙坚持九十天后的疲惫感，手机屏幕的冷白光是绝对视觉中心。
重点：逼仄出租屋和手机冷光，现代人孤独自律的压迫感

格2——【白光穿越异变】
视角：同一间出租屋在穿越瞬间发生异变，手机屏幕爆出刺眼白光，光线迅速扩散吞没床、桌面、墙面与人物轮廓，整个空间像被高亮光浪从内部撕开。房间里的日常物件在强光中失真、拉扯、边缘模糊，时间与空间有被掀翻的感觉，但画面仍要干净、可读，不做赛博科幻，而是“命运之门突然开启”的玄异感。
重点：手机白光炸开吞没出租屋，现实被强行撕裂的瞬间

格3——【风雪山路】
视角：元末武侠世界的风雪山路，夜色沉重，山道崎岖，地面被积雪和碎冰覆盖，风裹着雪粒横着刮过。远处是模糊山影和冷白雪面，近处能看到被踩乱的雪地痕迹、马匹或行路留下的压痕。环境不是壮美仙境，而是险、冷、痛，像一脚从现代摔进一个随时要命的江湖世界。画面中应能容纳人物倒地、扶胸、抬头相认的表演空间。
重点：风雪压脸的寒冷感，夜色中突然坠入武侠世界的生死危机

（格4-9留空）

## ep02 场景宫格

请生成一张 3×3 九宫格布局的电影场景环境图像。每个格子代表一个独立场景，所有格子必须保持视觉风格统一。请按照以下规范生成。

### 视觉规范
整体风格：国风武侠、真人写实、电影感构图，兼具名门大派寿宴的秩序感与公开逼迫的压迫感
色彩基调：木色、烛火暖金、殿内深红与灰白道门服色为主，整体暖中带冷
材质质感：武当大殿木梁、地砖、寿宴桌案、酒器、卷轴与古制兵刃都要有真实年代质感

### 宫格布局
第1行：格1 / 格2-9留空

### Panel Breakdown（场景拆解）

格1——【武当寿宴大殿】
视角：武当山寿宴大殿，白日。殿内空间高大开阔，粗重木梁与立柱结构庄严肃穆，地面为打磨光滑的深色石砖。正前方高位是张三丰所在主位，背后可见道门屏风、寿字陈设和整齐悬挂的卷轴。两侧寿宴长案上摆着酒盏、果盘和菜肴，但现场气氛并不喜庆，反而像一场公开审判。各派掌门与弟子分列两侧，服色各异，却共同形成压向中央的威势。大殿中央留出一块被所有目光围住的空地，适合张无忌、张翠山、殷素素被逼问、失控、崩塌的表演。烛火和天光一起照亮大殿，但越亮越显得人心冷硬。
重点：寿宴秩序与逼宫压迫并存的武当大殿，全场目光压向中央空地

（格2-9留空）
