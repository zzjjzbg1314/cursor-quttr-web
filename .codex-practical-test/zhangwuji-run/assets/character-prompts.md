# 人物提示词

## 张无忌（林川穿越后，ep01 新增）

**出图要求**：一张图，左半边面部特写，右半边全身正面、侧面、背面设定图，白色背景

**提示词**：

真人写实国风武侠角色设定图，电影感细节，白色干净背景。画面左半部分是面部特写，右半部分是全身正面、侧面、背面三个角度的设定图，水平排列，适配竖屏短剧角色立设，质感真实，皮肤、布料、发丝和风雪环境气质都要可信。

这是一位十四岁左右的少年，外表是少年张无忌，但眼神里有不属于这个年龄的现代人惊愕与强撑镇定。脸型清瘦，面部轮廓尚未完全长开，眉眼干净，眼睛较大但不稚气，瞳色深褐，眼神里带着刚经历剧变后的发懵、疼痛和不甘。鼻梁清挺，嘴唇偏薄，肤色因为寒毒与风雪显得苍白，唇色略淡，鼻尖和眼尾被寒风吹出一点轻微的红。黑发半束起，发量偏多，发丝被风雪打乱，额前碎发凌乱贴在皮肤上。

身高约一米六七，身形单薄但不孱弱，肩背还带着少年人的青涩。身穿元末武侠风格的旧棉布短袍与深色外披，整体以灰蓝、旧白、暗褐为主色，布料厚实但并不华贵，衣摆和袖口有轻微风雪湿痕。腰间束旧布带，没有夸张配饰，脚穿深色厚底布靴，带一点雪地泥痕。胸口姿态要有微微蜷缩感，像寒毒发作时下意识护住心口。

整体气质是“少年张无忌的身体里突然醒来一个现代灵魂”，不是传统热血少年，而是惊魂未定、嘴上会吐槽、心里已经隐约预感灾难无法回避的复杂状态。面部特写要重点表现风雪中的苍白、疼痛和清醒并存。

## 张三丰（ep02 新增）

**出图要求**：一张图，左半边面部特写，右半边全身正面、侧面、背面设定图，白色背景

**提示词**：

真人写实国风武侠宗师角色设定图，白色背景。画面左半部分为面部特写，右半部分为全身正面、侧面、背面三视图，整体具有电影级细节和古典武当宗师气质。

这是一位八九十岁的高龄道门宗师，正是张三丰。面容清癯，额头开阔，眉毛和胡须皆为银白色，胡须修长但不杂乱，双眼仍旧清明有神，眼神中有极深的慈悲、定力与见尽世事后的沉静。脸部皱纹自然清晰，尤其眼角、额头和法令纹处有岁月深刻痕迹，但整个人的精气神不能衰败，反而要呈现“年极高而气仍深”的宗师状态。肤色偏暖，像常年修行、气血深藏的老人。

发髻高束，道冠简朴，银白长发整齐收束。身穿武当道门长袍，主色为灰白、米白、旧青，衣料宽大厚实，层叠自然，下摆和袖口有古朴布纹。外披一件略厚的道袍或披氅，既符合寿宴场景，也保有山门宗师的清寂感。手中可持拂尘或自然空手，但姿态必须稳，站姿宽松含蓄，没有夸张发力动作。

整体气质是“以一人之定压住全场”的老宗师，温和中带无形威压，像只要他开口，整个大殿都会安静下来。他不是凶，不是冷，而是极强的稳定与包容。
