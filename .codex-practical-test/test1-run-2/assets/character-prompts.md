# 人物提示词

## 林书白（ep01 新增）

**出图要求**：一张图，左半边面部特写，右半边全身正面、侧面、背面设定图，白色背景

**提示词**：

真人写实国风玄幻角色设定图，白色干净背景。画面左半部分是面部特写，右半部分是全身正面、侧面和背面三个角度的设定图，水平排列，整体为竖屏短剧常用的人物立设质感，电影级细节，皮肤、布料和发丝都要真实可信。

这是一位二十岁左右的中国少年书生，面容清秀儒雅，脸型偏窄，额头干净，眉形修长，眼睛细长清亮，瞳色深褐接近黑色，眼底带着长期压抑后的疲惫感，但神情并不颓废，反而有一种经历生死后的淡定与清醒。鼻梁挺直，嘴唇偏薄，下颌线清晰但不锋利，肤色是略显苍白的冷白色，像常年埋头苦修、少见日晒的人。黑发束成文院弟子常见的低束发式，发冠简朴，额前有几缕碎发，发丝柔顺但不精致，带一点清晨刚醒后的自然凌乱。

身高约一米七八，体型清瘦修长，肩膀并不宽厚，但站姿有隐约挺直起来的变化，像一个原本长期低着头的人突然重新找回脊梁。身上穿一套青灰色旧式书院弟子袍，外层是洗旧了的粗麻长袍，颜色介于灰青和旧墨色之间，布料边缘有轻微磨损。内搭米白色交领中衣，领口干净但略显旧。腰间束一条深灰色布带，没有华贵玉佩，只有一枚磨旧的木质小牌和一只小布袋。袖口略宽，方便书写和行礼。脚穿一双深灰色布靴，鞋面干净但显旧，鞋底略薄。

他的整体气质不是张扬的天才型，而是被岁月和羞辱压过十年后，突然变得安静、冷静、带着隐忍锋芒的书生少年。正面站姿克制平稳，侧面线条清瘦利落，背面能看见旧袍在后背自然垂落的褶皱。面部特写里，眼神要呈现“刚从濒死与穿越冲击中醒来，但已经迅速镇定下来”的状态，既有余惊，也有重新观察世界的锐度。
