# 场景道具提示词

## ep01 场景宫格

请生成一张 3×3 九宫格布局的电影场景环境图像。每个格子代表一个独立场景，所有格子必须保持视觉风格统一。请按照以下规范生成。

### 视觉规范
整体风格：国风玄幻、真人写实、电影感构图，适配竖屏短剧的清晰前后景层次
色彩基调：整体以冷青灰、旧木色、晨光暖金为主，神文相关场景点缀低饱和金色光辉
材质质感：旧书院木梁、青石地面、粗麻布袍、潮湿山崖、带年代感的纸墨器物都要真实细腻

### Panel Breakdown（场景拆解）

格1——【青云文院简陋住处】
视角：青云文院弟子的简陋单人住处，清晨时分。房间不大，木质结构老旧，墙面有轻微开裂和岁月留下的灰痕。靠墙是一张窄木床，床褥单薄，青灰色被褥被睡乱，床边小桌上散着几本旧线装书、毛笔、砚台和半盏早已冷掉的油灯。窗纸破了细小一角，晨光从缝隙里斜斜照入，在地面和床沿形成一条暖金色光带。空气里有一点潮气和旧纸墨味，整个空间贫寒、克制、安静。
重点：清晨暖金光带切进灰暗旧屋，寒酸书生住处的压抑与静默

格2——【神文觉醒仪式场】
视角：十年前的青云文院觉醒仪式场，白天。宽阔的青石广场位于书院主楼之前，石地打磨得平整，但边缘已有岁月侵蚀的裂纹。广场中央是一块刻着古老纹路的黑石试文台，台面浮现若隐若现的金色文字纹理。后方主楼高大庄重，木梁飞檐，悬挂“文以载道，字为天则”牌匾。两侧站着身穿制式导师袍的长老和围观弟子，整体秩序森严，空气里带着考核场合特有的冷肃感。
重点：黑石试文台和金色神文纹路，庄重压迫的书院考核氛围

格3——【年度考核课堂】
视角：青云文院年度考核使用的基础课大堂，昨日白天。室内宽敞挑高，木梁粗重，墙边立着书架和卷轴架，前方是讲师案台，案台后悬着写有古文字的布幔。地面是深色木板，桌案排列整齐，窗外白光照入，与室内略偏冷的阴影形成反差。考核用的纸卷、墨砚和神文演示石板摆在台上，场地既有文院气质，也有当众审视的压迫感。
重点：讲师案台与演示石板，明亮窗光下的公开羞辱氛围

格4——【雨夜崖边】
视角：文院后山的崖边，夜雨中。天空阴沉，乌云压顶，细密雨线被山风吹斜，崖边的黑色岩石被雨水浸得发亮，石缝间有零散野草伏倒。远处山谷一片漆黑，只能隐约看到被风雨吞没的轮廓。崖边的气氛不是猎奇和惊悚，而是极度绝望与失重感，风声、雨声和空旷感压得人喘不过气。画面中不出现直接自伤动作，只保留站在崖边的孤绝背影和脚边滑落碎石的暗示。
重点：风雨压顶的绝望气氛，湿亮黑岩与深不见底的山谷

格5——【破旧小院远望主楼】
视角：住处外的小院，清晨。院子铺着不规则青石，角落有一口旧水缸和一株疏于打理的小树，围墙低矮斑驳。院门半开，晨光从门外洒入，照亮门槛和地面水痕。视线越过院子可以看到远处高起的文院主楼，飞檐与木梁在晨雾中显得既庄严又遥远。空间从私人寒酸小院过渡到宏大书院，带有“重新踏入世界”的意味。
重点：院门晨光与远处主楼的空间对照，个人命运与宗门秩序的距离感

格6——【青云文院主道与神文基础课门口】
视角：青云文院主道通向基础课课堂的大门，白天。主道由宽阔青石铺成，两侧是修整整齐的古树与回廊，晨后的光线已经转为清亮白日光。路上零散站着穿弟子袍的学员，远处可见“神文基础课”所在课堂的大门与牌匾，门扇厚重，门框木色沉稳。整个空间开阔公开，非常适合呈现被围观、被议论的社交压力，同时也承接主角昂首走入课堂的决心。
重点：长长主道尽头的课堂门口，公开审视与迎面而来的挑战感
