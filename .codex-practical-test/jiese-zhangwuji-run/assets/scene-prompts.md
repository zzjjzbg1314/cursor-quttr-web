# 场景道具提示词

## ep01 场景宫格

请生成一张 3×3 九宫格布局的电影场景环境图像。每个格子代表一个独立场景，所有格子必须保持视觉风格统一。请按照以下规范生成。

### 视觉规范
整体风格：国风武侠、真人写实、电影感构图，兼顾现代出租屋的克制冷感与光明顶大战的高燃爽感
色彩基调：现代段落以冷蓝灰和手机冷白光为主，穿越段落以纯白强光为核心，武侠段落以山岩灰、火把暖金、白衣亮点和冷风色温为主
材质质感：现代廉价出租屋的塑料、织物、旧墙面与手机玻璃质感清晰；武侠段落的山石、烟尘、兵器、木轿、锦缎与披风材质真实可信

### 宫格布局
第1行：格1-3 / 第2行：格4-5（格6-9留空）

### Panel Breakdown（场景拆解）

格1——【现代出租屋夜】
视角：一间普通年轻男性租住的小出租屋，深夜。空间狭小，墙面略旧，顶灯偏暗，床、书桌和地面有明显的独居生活痕迹，桌上有充电线、水瓶、纸巾、杂书和一部正在亮屏的手机。窗外夜色被旧窗帘挡掉大半，只剩一点城市冷光漏进来。整个空间压着一种长期克制欲望、熬夜坚持打卡后的疲惫感。
重点：手机冷白光和普通人独处深夜的压抑与完成感

格2——【白光穿越异变】
视角：同一间出租屋在穿越触发瞬间被高亮白光撕裂。手机屏幕像核心裂口，强白光瞬间吞没床、桌面、墙面与人物轮廓，所有日常物件在光里被拉扯、扭曲、失真，像现实空间被粗暴接管。画面不能做成赛博科幻，而要像一扇命运之门在最普通的房间里突然炸开。
重点：手机成为命运入口，现实被强行扯断的粗暴穿越感

格3——【光明顶主战场】
视角：光明顶大战正中战圈，白日大风。山顶石地开阔，尘土扬起，兵器碰撞，地上横七竖八倒着已经败退的人。六大门派与明教残阵在两侧拉开对峙，战场中央留出明显落点，适合从天而降、接掌战局和高燃反打。远处可见山岩和旗帜，整体有大战压顶与局势一触即发的紧绷感。
重点：大战中央落点明确，适合男主空降和连续反打

格4——【光明顶战后拜服中心】
视角：大战刚止的光明顶空地，风仍然在吹，尘土未完全落下。战场中央留有一片被众人围住的空地，周围散落兵器、碎石和还未撤去的大战痕迹。明教众人适合在这里大面积跪拜、杨逍行礼、男主站在正中接受全场视线。这里既有胜利余温，也有“权力刚落下来”的新秩序感。
重点：群像拜服、男主居中站定、系统警告膨胀的爽文名场面

格5——【远处山坡赵敏观战点】
视角：距离光明顶主战场较远的一处高地或山坡，地势略高，可以俯视战局。停着一顶华贵轿辇，帘幕被山风掀动，周围站着持兵器的护卫和随从。这里和主战场的热闹相反，气氛冷静、贵气、危险，像一个真正看局的人在欣赏突然出现的新变量。
重点：赵敏远观张无忌时的兴趣、掌控欲和危险暧昧

（格6-9留空）
