# 人物提示词

## 张无忌（林川光明顶版，ep01 新增）

**出图要求**：一张图，左半边面部特写，右半边全身正面、侧面、背面设定图，白色背景

**提示词**：

真人写实国风武侠男主角色设定图，电影级细节，白色干净背景。画面左半部分是面部特写，右半部分是全身正面、侧面、背面三视图，整体适配竖屏短剧的强男主视觉。

这是一位二十岁左右的青年，外表是光明顶时期的张无忌，但眼神里带着现代普通青年突然空降男主位后的惊喜、自信和一点忍不住的得意。脸型清俊，眉骨干净，眼睛明亮有神，瞳色深褐，眼神既有少年侠气，也有“我居然真的穿成张无忌了”的鲜活反应。鼻梁挺直，嘴唇线条清晰，肤色偏白但有江湖行走后的健康气色，嘴角常带一点压不住的上扬弧度。

黑发半束，发量浓密，发尾自然披散，发丝被山风轻微吹动。身形修长结实，不是魁梧壮汉，而是内功深厚的轻灵型男主。身穿白色或米白色武侠长袍，内层为简洁交领，外层披带轻薄但有分量感的长衣，腰间束深色腰封，布料有细腻纹理和少量战斗后的灰尘痕迹。袖摆宽而利落，便于出掌和转身。脚穿深色武侠布靴。

整体气质要呈现“守住九十天后终于吃到男主红利”的爽感，但不是油滑轻浮，而是刚接住巨大命运、体内神功稳定、越打越顺的兴奋。面部特写重点表现高燃、自信、灵光一现的男主状态。
