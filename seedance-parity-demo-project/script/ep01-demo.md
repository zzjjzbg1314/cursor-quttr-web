# ep01 便利店夜雨

## 题材

都市情感短剧

## 视觉风格

写实电影感，冷暖对比明显，夜景有潮湿反光。

## 剧情正文

深夜，小雨刚停，林薇加完班走进街角便利店。她穿着被雨气打湿的深灰色西装外套，手里还攥着没有来得及回复的手机。便利店里灯光明亮，和门外发冷的蓝色街景形成反差。

她站在热饮柜前发呆，视线落在一排罐装咖啡上，却迟迟没有伸手。收银台后的周然抬头看见她，认出这是最近总在深夜出现的女顾客。他没有立刻搭话，只把刚热好的关东煮轻轻放到保温台边。

林薇终于拿起一罐黑咖啡，走向收银台。扫码时她的手机屏幕亮起，显示“妈妈”发来的未接来电和一串语音消息。她下意识按灭屏幕，神情更紧。周然看了她一眼，平静地说：“今天新到的姜茶不苦。”语气像是随口一句，却带着一点试探的关心。

林薇愣了一下，目光从手机移到他脸上，防备感慢慢松开。她把黑咖啡放回柜台，改拿那杯冒着热气的姜茶。她低声说了一句“谢谢”，声音很轻，像怕这点温度一说出口就散了。

离开前，她站在便利店门口看着湿漉漉的街道，玻璃门映出她略显疲惫却终于缓和下来的表情。店内暖黄灯光落在她肩上，门外远处车灯从积水路面划过。周然隔着玻璃看着她，没有追出去，只是把收银台边那台小音箱的音乐轻轻调低。这个夜晚没有发生大事，只是两个陌生人之间，出现了一点点可以让人继续往前走的暖意。
