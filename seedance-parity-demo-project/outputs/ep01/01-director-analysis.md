# ep01 导演讲戏本

## 项目头信息

- 集数：ep01
- 标题：便利店夜雨
- 题材：都市情感短剧
- 视觉风格：写实电影感，冷暖对比明显，夜景有潮湿反光

## 一句话 Logline

一个被工作和家庭消息压得透不过气的都市女性，在深夜便利店里，因为陌生店员一句克制的关心，重新接住了一点继续往前走的力气。

## 导演讲戏本

## P01 夜雨入店

- 人物：林薇
- 场景：雨后便利店门口、便利店入口
- 镜头组：多镜头（2组）
- 时长建议：8s

**导演阐述**：
开场先给一个夜雨刚停的街角建立镜头，路面积水还在反着蓝白色的街灯，便利店的暖黄色灯箱在湿冷空气里格外显眼。镜头从街对面略带距离地看见林薇快步走来，她深灰色西装外套被潮气压得发沉，肩头有很轻的湿痕，手里紧握着手机却没有看屏幕。镜头随着她靠近门口，玻璃门自动滑开，室内明亮干净的白光一下子扑到她脸上，把她脸上的疲惫照得更清楚。第二组镜头切到她从门外冷蓝街景迈入店内暖光的瞬间，人物情绪从紧绷过渡到一种被短暂包裹住的失重感，环境音里有便利店门铃轻响、远处轮胎压过湿路面的水声和店内空调稳定的低鸣。

## P02 热饮柜前停顿

- 人物：林薇、周然
- 场景：便利店热饮柜区
- 镜头组：单镜头
- 时长建议：8s

**导演阐述**：
中景停在热饮柜前，林薇站在一排罐装咖啡和姜茶之间，视线落在玻璃柜里，却迟迟没有伸手。她的动作很少，只是手指在手机边缘无意识地磨蹭，肩背并没有真正放松下来，呼吸轻而浅。镜头缓慢从她身侧挪一点角度，把收银台后的周然纳进背景，他抬头认出她，却没有贸然出声，只是顺手把刚热好的关东煮放到保温台边，动作温和、克制，没有打破她此刻的静止。店内光线是偏白的顶光，玻璃热饮柜把光打回她脸上，显得她的黑眼圈和紧绷下颌更清楚，空气里有热柜轻微的机械运转声和很轻的背景音乐，整段情绪是安静、压着的。

## P03 收银台与姜茶

- 人物：林薇、周然
- 场景：收银台
- 镜头组：多镜头（3组）
- 时长建议：10s

**导演阐述**：
先用一个中近景跟着林薇把黑咖啡拿到收银台，她把东西放下时动作带着惯性的疲惫，像只是想靠这点苦味撑完今晚。扫码瞬间，手机屏幕亮起，镜头切到她掌心附近，屏幕上是“妈妈”的未接来电和一串语音消息，蓝白色冷光从下往上打在她脸上，让她表情一下更绷。她几乎是条件反射地按灭屏幕，目光也随之垂下，情绪往里收。第二组镜头切到周然的视角，他看了她一眼，没有追问，只平静地说：“今天新到的姜茶不苦。”这句台词要说得像顺手给出的一个退路，不煽情，也不刻意安慰。第三组镜头回到两人之间，林薇愣了一下，抬眼看他，防备感慢慢松下来，她把黑咖啡轻轻推回去，改拿起还在冒热气的姜茶。台面上的暖黄灯光和热气把这个动作托得很轻，环境音保留扫码“滴”声、保温台的细小水汽声和两人说话间的短暂停顿。

## P04 门口余温

- 人物：林薇、周然
- 场景：便利店玻璃门口、雨后街道
- 镜头组：多镜头（2组）
- 时长建议：8s

**导演阐述**：
离店前先给林薇一个站在玻璃门口的侧身中景，她手里捧着姜茶，热气在暖色灯光里往上浮，肩线终于松下来一点。她看向门外湿漉漉的街道，远处车灯划过积水，反光在玻璃和地面上流动，她脸上的疲惫还在，但表情已经不像刚进门时那样拧紧。第二组镜头隔着玻璃拍周然，他站在收银台后面看她，没有追出去，只伸手把旁边小音箱的音乐轻轻调低，让这个夜晚安静地收住。结尾让林薇在门边停半秒，像是把这点温度留在身上，再自然地推门走进夜色，画面和情绪都停在“事情没有解决，但人被接住了一点”的余韵上。声音上保留杯盖碰指尖的轻响、门外远处车流、室内被调低后的音乐尾音。

## 给服化道的交接

- 林薇的重点是“都市高压状态下的精致疲惫”，不要做成狼狈或邋遢，她仍然是讲究但被消耗的。
- 周然的重点是“有分寸的温和”，外形干净、普通、可信，不要做成偶像化或攻击性强的店员。
- 场景必须突出冷暖反差：门外是湿冷蓝调，门内是亮而不过曝的便利店暖光。
- 收银台与热饮柜要有真实便利店细节，例如保温台、扫码器、商品排布、玻璃反光和小音箱。

## 给分镜的交接

- 节奏整体偏克制，动作不多，重点在情绪松开的几个细节动作。
- 林薇的动作链要真实：停顿、看屏幕、按灭、抬眼、换饮料、捧住热杯。
- 周然的表演分寸很重要，他的动作要少，但每次出手都刚好。
- 声音设计要把“深夜便利店的安静”保留下来，环境音不能空。

## 风险与未决问题

- “妈妈”的信息只以手机和语音存在，本集不单独设计人物参考图。
- 当前文本能确认林薇与周然为长期可复用角色，后续若母亲进入正面戏份，再新增人物素材。
