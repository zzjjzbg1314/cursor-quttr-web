# 模板主题收敛改造

## 目标
推荐｜生日｜爱情｜家庭｜宝宝｜友情｜纪念日｜婚礼｜校园｜旅行｜日常｜励志。
推荐是排序入口；其余 11 个为平级主题，不提供二级分类。保留一个主分类和按需关联分类。

## 已完成的代码
- 三个项目使用相同的 template-topics.json；管理端契约测试验证三份内容一致。
- 录入、批量归类、编辑及筛选改成单层主题，人工保存锁定分类。
- 推荐复用目录 sortOrder，管理端详情可编辑，未填写时保留原排序。
- 网站首页、公开目录、工作区和分类页统一主题入口；旧分类页面兼容跳转；主分类改变后旧模板地址仍可解析。
- 自动分类优先具体内容，宽泛来源栏目不能独立决定归属；明确追思内容要求人工确认；结婚周年优先纪念日。
- 新增 /admin/template-topic-guide.html，模板管理页、详情页和侧栏提供入口，含 11 个主题定义及易混淆案例。

## 数据迁移
网站后端的显式 D1 初始化升级到 schema 14。分类切换在一个 D1 批次执行，保留 template_taxonomy_history 中的原主分类及关联证据。可确定的历史类别映射到新主题；未确定的旧主分类保留，初始化响应 taxonomyReview 列出待处理模板。停用关联分类从当前关联表移除，历史快照独立保存。重复迁移不会复活已移除的旧关联。

改造前通过本地管理 API 读取到 9 个公开模板：纪念日 2、情侣 1、宝宝与孩子 1、生日 3、父亲节 1、家庭 1。按已有分类均能确定映射；父亲节并入家庭。该盘点只确认分类映射，不冒充逐个视频内容复审。
