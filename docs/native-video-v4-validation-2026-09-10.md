# 原生视频 v4 运行契约与基础导出

## 改造范围

新视频场景经严格规划后可生成 browser-native-scene-runtime-v4，显式 videoAudioPolicy=external_music_only。视频原始字节从网站资源列表取得，由官方 Blob IO 和时间线解码；视频、图片、固定图、文字的执行归属与合成检查保持明确。v1/v2/v3 保留原执行归属。当前仅支持已绑定的单位速度视频，缺原始速度、未知模式或曲线继续阻断。

研究端自动收集视频效果、动画、转场的实际最小依赖。网站后端验证 v4 和音轨策略，并允许明确的零照片槽位视频场景；浏览器仍校验完整执行语义。客户浏览器不依赖 8082。

## 明确边界

这不是新 0909 的完整导出或 SSIM 验收。此处只验证 1.4 秒无额外效果的视频场景，不能外推到长视频、变速曲线、带历史状态效果或视频原声混音。较大取帧任务的 64 MiB 缓冲限制仍需后续处理；未据此退役其他实现。

客户真实编辑、云端保存、导出上传的完整闭环以及已上架批量迁移仍未完成。已发布版本未改变。8080/8082 尚未重载本轮 Java 修改。新 0909 尾帧 SSIM 问题仍未解决。
