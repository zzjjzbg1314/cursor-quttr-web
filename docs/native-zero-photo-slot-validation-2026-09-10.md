# 原生固定图片零照片槽位验证

后端原先只接受纯文字零照片槽位场景，导致 v3 固定图片场景在准备客户渲染任务时被拒绝。本次将入口检查扩展到已保存、ready 的固定图片及文字混合场景。要求 v3 原生描述符、合法同源 SDK 与最小依赖、固定图片资源引用、唯一图层身份和完整基础字段。照片槽位缺失、未知图层、旧描述符和缺失依赖继续阻断。完整效果、时钟和合成语义仍由浏览器规划器验证。

## 检查

- Java 8 编译通过；MusicMvRenderJobServiceTest 26 项、BrowserNativeRuntimeContractTest 7 项通过。
- 新增测试覆盖有效固定图片、文字混合、旧版本、缺少交付、缺少图片、缺少 clip、照片层、重复层、缺少效果依赖、多余绑定及非 ready 场景。
- 基础验证使用独立固定图片夹具，从归档场景抽取四个固定图片层并保留其原始参数；不是整个 0905 模板验收，不是 SSIM。
- 首次夹具未同步移除 Render IR 的照片层，被交错图层检查阻断；修正夹具后重试成功。生产校验未放宽。
