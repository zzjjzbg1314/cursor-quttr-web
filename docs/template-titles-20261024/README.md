# 58 个模板标题十语言同步

本轮只扩展模板标题：保留简体中文、英文源名，新增繁体中文、日语、韩语、西班牙语、巴西葡萄牙语、法语、德语、意大利语，共 464 个新增标题、580 个完整标题。

- `translations.json`：按模板 ID 记录源名、源发布版本及人工复核译文。
- `before.json` / `after.json`：同步前后的标题、说明、资料 revision 和发布版本快照。
- `sync-log.json`：58 个模板的成功写入记录。
- `online-verification.json`：通过线上网站代理接口抽查的校验结果（全量 HTTP 探测发生读取超时，数据库已全量验证）。

同步前完整校验模板集合、源名和发布版本；先以两个 SELECT 验证 D1 批量协议。每个模板单独执行包含源名及 revision 条件的九条语句事务，仅新增/更新八种目标语言的 name，最后递增资料 revision。保留原有说明及 current_version_id，不修改素材、运行包或模板视频。读回数据库确认全部 580 个标题准确，原中英文标题/说明和发布版本均未变化。

本轮运行中的服务尚无新标题同步接口，因此使用与新增接口一致且经过 SQLite 测试的参数化事务，直接同步它连接的线上 D1。未重启正在运行的服务，未部署其他未提交改动。

网站列表按十种语言读取、未来新增模板自动翻译的代码已另行提交；线上旧版本的列表查询仍将日语等归为中文，需要发布前后端代码后才会在所有列表正确显示。线上详情接口能够返回已同步的十种语言标题。模板标题数据同步不等同于代码部署。

未来模板仍由 pengyouquan-web 的新增/同步入口送到网站后端；网站后端负责补齐标题并执行发布检查，避免多处重复翻译。配置和接口契约见 ../template-title-localization.md。
