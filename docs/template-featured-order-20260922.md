# 前台模板精选优先排序验收

2026-09-22

## 规则

网站公开模板共用数据库排序：运营权重降序 → 已同步且布尔值为真的精选优先 → 发布时间降序 → 更新时间降序 → 模板 ID 升序。排序在 LIMIT/OFFSET 分页之前执行。

普通、未知、缺失、无效 JSON、字符串 true 均不提升优先级。后台管理列表保留原有排序。

## 覆盖入口

首页推荐及分类切换、全部模板、分类、场景专题、搜索和技术筛选、编辑器模板选择、AI 歌曲转视频介绍页都调用同一个公开模板查询；前台不进行二次重排。加载更多按页追加并去重。详情相似模板复用同一查询，按当前主分类筛选并排除自身。中英文使用同一排序。

## 验收

- Repository 17 项、Service 97 项测试通过。
- SQLite 执行实际排序片段，覆盖高权重普通模板优先、精选新旧顺序、普通新旧顺序、异常和未知数据、同时间 ID 稳定顺序、低权重精选，以及连续四页结果。
- 英文和中文、分类/合集/标签/搜索调用产生相同的排序片段。
- 本地 8080 已加载新版本。真实接口返回 81 条公开模板，其中 39 条精选；前 10 条均为精选。
- 真实接口验证：中英文顺序一致；每页 30 条拼接与全量一致；生日分类、生日标签、5–10 张照片筛选均保持全量相对顺序；相似模板与同分类过滤结果一致；3000 前台代理与 8080 顺序一致。
- 仅查询排序变化，不涉及渲染，不执行视频渲染或 SSIM。
