# 模板旧素材清理

同步替换图片或视频时，在同一个数据库批次中先登记旧云端对象，再替换或移除素材关联。待清理记录保存在 `template_media_cleanup`，服务重启不丢失；表由服务首次使用时幂等创建。

后台启动一分钟后开始检查，默认每小时一轮，每轮最多 50 个对象。可通过 `music-mv.template-media-cleanup-interval-ms` 调整轮询间隔。只处理登记满 24 小时的对象。

删除前检查云端对象是否仍出现在模板媒体或浏览器场景中；原模板只要还有项目或渲染任务，或原版本有尚未就绪的素材，就保守保留。无法确认引用状态时不删除。被引用或失败的任务推迟一天重试，成功后移除队列记录。云端文件已经不存在时按删除成功处理。

仅处理 Cloudflare Images 和 Stream 中后续同步替换的对象，不扫描整个云端账户，不处理运行包或用户上传文件，也不追溯已经丢失对象关联的历史文件。实际云端删除不可恢复。已有作品较多的模板可能长期保留旧素材，这是避免破坏旧作品的保守策略。

验证只使用模拟云端接口，不实际删除云端对象，不执行渲染或 SSIM。
