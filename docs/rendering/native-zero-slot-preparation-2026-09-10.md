# 纯文字模板空图片绑定准备

网站任务准备原先无条件拒绝零照片槽，导致研究端和浏览器已经支持的纯文字模板不能进入浏览器就绪状态。现在仍先检查模板及请求版本已发布、browser_ready 与场景 ready；空槽位仅在请求无图片绑定，且保存的 v6 场景明确声明 slots、timelineSegments 均为空、非空图层全部为唯一文字、textLayers 对应所有图层并保留原始文字源声明时允许。

新增检查只解决空照片绑定的资格判定，不替代发布时的完整语义验证或前端执行检查。场景缺失、未就绪、含照片图层、槽位声明不一致、文字原始源缺失和额外图片绑定仍拒绝；照片模板原有资产归属检查保持不变。

相关 Java 编译通过；任务服务 25 项、仓库 9 项、控制器 7 项测试通过。新测试使用已发布版本和模拟持久场景，覆盖一个成功及六个拒绝分支，未创建真实客户任务。

最终代码后的代表性浏览器基础用例 migration-native-zero-slot-backend-validation 成功：1080×1920、30fps、60 帧、2 秒，exact，编码一次，中间视频零，无 Writer 残留；渲染记录耗时 0.943655 秒，总记录耗时 2.463705 秒。该用例通过生产浏览器执行器使用研究端生成的纯文字交付描述，不能当作真实账号经 8080 准备、保存和导出的全链路证明。

未运行 SSIM。本提交不解决 0909 原始尾帧差异，亦不证明客户页面已支持零照片编辑流程或全部场景迁移完成。
